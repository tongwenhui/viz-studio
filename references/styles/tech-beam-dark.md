# tech-beam-dark 暗夜光束 · 风格分册

> 一句话：深空暗底上一束光源，文字在光外呼吸——发布会 / 年会 / 讲座 KV 的默认重器。
> 来源：case-01 TCL CES（A）/ case-02 HONOR Magic4（B）/ case-03 暗金邀请函（C），2026-09 像素实测蒸馏。状态 **v3 定稿（2026-09-21 两轮批注收敛：v2 提密度爆度，v3 去细亮芯）**。
> 叠加遵守 `guardrails.md`，冲突时按其 §10 优先级。所有 hex 均为当日实测值，标注「→」的为应用 token（实测含抗锯齿，按 oklch 提亮一档补偿）。

## 变体总览

| 变体 | 光效语言 | 排版轴 | 适用 | 信息量 |
|---|---|---|---|---|
| A 彩色光束放射 | 冷左暖右双扇面 + 白星芒 | 居中单轴，无衬线 | 发布会 / 展会 / 年会 KV | 2–3 组 + 底部微字 |
| B 弧光星球 | 单一金弧 / 星球 + 深空 | 居中单轴，无衬线，克制 | 倒计时 / 预告 / 高端发布 | 1–2 组 |
| C 暖金绸光 | 金色绸缎流光 + 颗粒 | 左对齐编辑轴，衬线 | 邀请函 / 请柬 / 晚宴 | 3–4 组纵向叙事 |

---

## 1. 画布与安全边距

- 横版 KV 1920×1080（scale 2 导出 4K）；竖版延展 1080×1920；C 变体邀请函 1080×1920。
- 【硬】文字与 logo 四边安全边距 ≥96px（画布宽 5%）；光效可贴边出血。
- 星芒中心默认 (50%, 61.5%)——即光域在地平线，文字在上半场，信息带在下半场。
- C 变体：巨字可出血裁切（case-03 的 INVITATION 左右顶边），但中文大字与正文不出血。

## 2. 色彩五角色 tokens

五角色 + 本风格专属光束族（beam 族只许出现在光域内）。

### A 变体（TCL 实测）

```css
:root {
  --c-bg: #151628;          /* 画布基底，四角实测 */
  --c-bg-lift: #232533;     /* 中上部提亮，垂直渐变终点 */
  --c-glow-warm: #6f275e;   /* 底部暖紫辉光，35% 透明径向 */
  --c-ink: #ffffff;         /* 主文字（实测 #feffff） */
  --c-muted: rgba(255,255,255,.78);
  --c-primary: #2276ed;     /* 冷调光束主色 */
  --c-accent: #ee1005;      /* 暖调光束（只在光域内） */
  /* 光束族（光域专用，正文区禁用） */
  --beam-royal: #1328ab;  --beam-blue: #2156c1;  --beam-indigo: #5b63df;
  --beam-peri: #a6b8ef;   --beam-cyan: #46aacc;
  --beam-red: #d4363e;    --beam-dark-red: #941a3f;
  --beam-mauve: #c678ab;  --beam-peach: #fdcf9f;
  /* 信息带三色：实测 #6da3d8 / #cb9b82 / #c95e68（含抗锯齿）→ 应用值 */
  --band-blue: #74aade;  --band-gold: #d8a874;  --band-red: #d1636e;
}
```

### C 变体（暗金邀请函实测）

```css
:root {
  --c-bg: #211a0d;          /* 底部深棕，向 #6e4d2a / #764c27 绸面高光渐变 */
  --c-ink: #f2dec5;         /* 米金奶油，中文大字实测 */
  --c-muted: rgba(242,222,197,.78);
  --c-primary: #a88b70;     /* 绸面金（衬线巨字主色） */
  --c-accent: #cdb595;      /* 亮金（引言 / 关键词） */
  --gold-deep: #9a7150;  --ink-dark: #13100c;
}
```

面积比：60 深底 / 30 光效+白字 / 10 强调（星芒或金色）。C 变体的 cream #f2dec5 是「白」的暖替，**全册禁用冷纯白当大字**（C 语境）。

## 3. 字体栈

| 职 | A / B 变体 | C 变体 |
|---|---|---|
| 标题 | Roboto Flex VF（wght 300–800 真字重，Apache 2.0） | EB Garamond（400 + Italic，OFL）英文巨字 / 引言 |
| 中文 | MiSans（免商用） | 思源宋体 Noto Serif SC VF（OFL） |
| 数字 | 同标题族 + `font-variant-numeric: tabular-nums` | 同衬线，日期大数字可 700 |

- 离线加载：项目字体库 `fonts/english-roboto-flex/RobotoFlex-VF.ttf`、`misans/MiSans-Regular.ttf`、`english-eb-garamond/*`、`source-han-serif/NotoSerifSC-VF.ttf`，`@font-face` 相对路径引入，禁 CDN。
- fallback：`'Roboto Flex','Helvetica Neue',Arial,sans-serif`；`'EB Garamond',Georgia,'Times New Roman',serif`；中文回退系统黑体/宋体。
- A 变体主标典型用法：**同行双字重**——前半 800 + 后半 300（「INSPIRE GREATNESS **Join TCL at CES 2026!**」）。

## 4. 字号阶（1920×1080 基准，case 实测 ×1.6 换算）

| 层 | A 变体 | B 变体 | C 变体（1080×1920） |
|---|---|---|---|
| 徽标/字标 | 56–72 | 48–64（角落） | — |
| 主标 | 60–76 | 产品名 64–80 | 中文大字 170–200/字；英文衬线巨字 130–160 |
| 口号/副题 | — | 32–40 | 斜体引言 28–32 |
| 信息行 | 26–30 | 26–30 | 正文 40–48 |
| 大行动语 | — | 52–64（WILL START SOON 级） | 日期大数字 90–110 |
| 信息带/标签 | 24–28（600） | 频道胶囊 18–20 | meta/眉题 18–22 |
| 底部微字 | 18–20 | — | 底部信息行 20–24 |

- 竖版延展 1080×1920：主标 ×0.85，信息带改纵向堆叠。
- 【硬】主标与信息行字号差 ≥1.8 倍（本风格靠「巨字 vs 微字」的极端对比立骨）。

## 5. 网格与间距

- **居中单轴**（A/B）：全部文字块水平居中于 x=50%，一条轴贯穿徽标→主标→信息→底部；8pt 基线。
- A 变体垂直节奏（1920×1080）：徽标行 y≈96 → 主标 y≈288 → 信息行 y≈388/442 → 星芒 y≈664 → 标签 y≈812 → 信息带 y≈872 → 微字 y≈996。
- 文本列宽 ≤62% 画布宽（≤1190px）；正文每行 ≤22 字。
- 信息带：3 栏 inline-flex，栏距 48–64px，白色细分隔线 1px×72px（rgba(255,255,255,.4)）。
- B 变体：文字块压在下半场 55%–90% 区间垂直居中，上半场全让给光效。
- C 变体：左对齐编辑轴 x≈6%；右下角时间块（TIME meta → 大日期 → 时段 → 祝语）；TO/称谓用**竖排字 + 1px 长竖线**；底部信息行三段式（左标语 / 中编号 / 右 QR）。

## 6. 布局原型（按要点数）

| 要点数 | 原型 | 说明 |
|---|---|---|
| 1 | B 型 | 光效占上半 45%，单行大字 + 一行时间 |
| 2 | B 型或 A 简版 | 产品名 + 口号；或主标 + 时间地点 |
| 3 | A 型标准 | 徽标行 + 主标 + 时间地点 + 光域 + 三栏信息带 + 微字 |
| 4+ | **不适用本风格** | 拆延展页，或转 `data-graphic` |
| 邀请函 | C 型纵向 | meta 行 → 英文巨字 → 中文大字叠压 → 斜体引言 → 中文正文 → TO/竖排称谓 → 时间块 → 底部信息行 |

## 7. 组件语言（含光效配方）

**星芒**（全图唯一光源，v2 炸裂版）五层：
1. 核：径向渐变白圆 88–96px，中心纯白占比 ≤30%（30% 处仍 ≥.8 白）；
2. 主十字光：水平 1080–1200×3px + 垂直 320–360×3px，中段 42%–58% 区间维持 ≥.95 白；
3. 斜光翼：±45° 两道 380–440×2px，opacity .5–.65，成 8 向星；
4. 镜头拉丝（anamorphic）：水平 1400–1600×44–56px 椭圆辉光 rgba(255,255,255,.14–.18)→transparent 70%；
5. 外晕：560–640px 径向 rgba(255,255,255,.24–.28)→0（42% 处 .07）。

【硬】爆度下限：外晕直径 ≥ 画布宽 28%，主十字水平长 ≥ 画布宽 55%；不达线即为「收敛」，判不合格。

**光束扇面**（A，v3 全柔化）：每条 = 绝对定位渐变条，`transform-origin` 钉在星芒点，rotate 张成扇面，`mix-blend-mode: screen`；**冷扇 10–12 条 + 暖扇 10–12 条**，角向间隔 2°–4° 连续铺扇不露底；主条高 24–56px，亮色（--beam-peri / --beam-peach）以 22–28px 柔光带（`blur(6–7px)`，opacity .7）夹在宽条之间提明度层次，**禁「细亮芯」**；1/3 的宽条加 `blur(4–10px)` 造景深；色相 ≤6 族（同族复用多条，靠明度差分层）；近星芒端亮、末端渐隐（`linear-gradient(90deg, var(--beam-x), transparent)`）。底线再叠两侧主束色的椭圆反光 + 底部 `--c-glow-warm` 辉光。【硬】密度下限：任一扇面条数 <10 即「稀」，判不合格。【硬】细亮芯禁令：条带高 <16px 必须配 `blur ≥2px`，无 blur 条带高 ≥18px；不达即「锐线穿帮」，判不合格。

**弧光**（B）：椭圆 2px 金描边 + conic-gradient mask 渐隐两端，交点叠暖白 bloom；星球 = 深色圆 + 单侧 rim 光。

**徽标行**：字标 + 1px 竖分隔线（≥56px 高）+ 线条徽标（白描边图形，禁彩色 logo）；下方可缀 18–20px 说明行。

**信息带三栏**：栏标题用 `--band-*` 三色各一，600 字重，每栏 ≤2 行手动断行；分隔线白色 1px。三色是光域语言在文字区的唯一延伸，**除此之外文字区不出现彩色**。

**频道胶囊**（B）：1px 白描边、8px 圆角、透明底；内联 SVG 图标 + handle 文字。

**C 变体专属**：括号 meta「(2025-)」、竖排称谓 + 长竖线、全角斜杠大日期「11／25」、白底 QR 块、颗粒噪点纹理（opacity ≤8%）。

## 8. 调性禁则

1. 【硬】单一光源：全图只有一个星芒/弧光焦点，禁第二光源平分亮度。
2. 【硬】文字永不压光束核心；文字区落位在暗区，对比 ≥4.5:1（guardrails §4）。
3. 【硬】A 变体的强调预算已被光域占用，文字区禁再用彩色强调（信息带三色除外）。
4. 【硬】光束色相 ≤6 族；禁紫→蓝渐变底、禁彩虹满铺（guardrails §4/§5）。
5. 【默认】B 变体金色是唯一彩色，彩色元素 ≤1 处（胶囊图标可用品牌色破例）。
6. 【默认】光效禁描边、禁噪点以外的纹理；禁锥形渐变直接铺彩虹。
7. 【默认】信息 ≤3 组 + 底部微字 1 行；更多内容 = 拆延展页。
8. 【硬】字体 ≤3 款；A/B 禁衬线混入，C 禁无衬线大字（族内纯度）。
9. 用户反参照置顶（guardrails §10.1）。
