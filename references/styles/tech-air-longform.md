# tech-air-longform · 浅色科技长图（白蓝渐变 × 玻璃飘带 × 圆角卡）

> 一句话：白→浅蓝长渐变底上一条蓝紫玻璃飘带占住上半屏，中段左对齐纯黑大标题（强调词品牌蓝），下接一张比底色深半档的大圆角信息卡（正文级强调只用字重），居中黑粗收尾行+灰色副行——典型 OS/产品发布长图语法。

## 变体总览

| 变体 | 案例 | 特征 |
|---|---|---|
| A 竖版长图（本册主体） | case-01 ColorOS 14 预热 | 1080×1920 单屏：logo + 飘带 + 标题 + 单卡 + 居中收尾 |

多屏延展：公众号推文长图按 §6 原型 B 纵向堆叠（每 1920px 一屏一重点），飘带只在首屏出现。

## 1. 画布与安全边距

- 画布 **1080×1920（9:16 手机整屏）**，案例 658×1169（k=1.6413）。
- 文字安全边距：正文/标题左缘统一 **x=103**（案例 63）。
- 卡片边距：卡片左右 **x=54–1024**（案例 33–624），比文字边距更贴边——卡片比文字宽是本族层级语法。
- 底色：`#ffffff → #c8d8f9` 长渐变（§2），禁止纯灰白平涂。

## 3. 字体栈（≤3 款）

- 全部文字单款封顶：**Noto Sans SC VF**（400/500/700/900 可变字重）——原案例 OPPO Sans 的替身，其 Latin 为 Source Sans 系，与 OPPO Sans 几何人文气质吻合，数字/西文同款。
- 禁衬线、禁楷/宋（本族是纯 UI 科技感）。
- 挂载路径（相对 `trials/tech-air-longform/`）：`../../fonts/source-han-sans/NotoSansSC-VF.ttf`。

## 6. 布局原型

- **原型 A · 单屏单卡**（case-01）：logo → 飘带视觉主体（上 40%）→ 标题组 → 引导行 → 信息卡（≤2 段）→ 居中收尾组。信息密度低、留白多。
- **原型 B · 多屏堆叠**：首屏走原型 A，后续每 1920px 一屏 = 小节标题（48px/700，x103）+ 卡片或图文组 + 居中过渡句；飘带降级为角部切片（不重复全屏主体）。
- 按要点数选型：1 个卖点 → 原型 A 单卡 2 段；2–4 个卖点 → 原型 B 每屏一卡；≥5 个 → 改用 data-graphic 族。

## 7. 组件语言

### 7.1 玻璃飘带（命名级特征）

案例是 3D 渲染的半透明环带：左侧收成锥尖（深蓝紫 #2f23ff 集中处），环体向右上翻卷出画，环心透空见底，右下拖出渐细尾。

- 【硬】**生产级出图必须优先真实 3D 素材**（透明底/浅底蓝紫玻璃质感 PNG），SVG 配方只作兜底并在交付时声明——v2 用户批注：SVG 线条感太强，「没有那种玻璃质感」，正式物料不可直接充当 3D 主体。
- 素材主题可按内容更换（v3 确认）：命名级特征是「玻璃质感 3D 物件占住上半屏」，环带只是 case-01 的实例；出图时按文案主题选同材质语言的 3D 物件（如文档+放大镜配「识文/效率」主题）。
- **素材版位（v4 用户批注定案）：偏右上、右缘出血**——对齐 case-01 环带的版位（环顶 y115 / 右肢贴右缘出画）。操作：素材先裁掉透明边（PIL `getbbox()`+`crop`）再入库，按原始宽高比放大渲染，`left = 1080 − 宽 + 出血量`（本例 860 宽、出血 160 → left 380），`top` 避开 logo 带（本例 130）；海报容器 `overflow:hidden` 裁净出血。禁水平居中死放（v3 布局已被此条取代）。
- 素材合成法（v3 实证，`trials/tech-air-longform/replica-case01.html`）：透明底素材以 `<img>` 置入 hero 区，**保持原始宽高比**、`width`/`height` 显式声明；一道柔和投影 `drop-shadow(0 26px 50px rgba(47,84,166,.20))` 出悬浮感，透明底直接融进 bg 渐变，**禁 multiply**（会把素材白区染蓝）。浅底不透明素材才用 `mix-blend-mode:multiply`。
- SVG 兜底配方（画布坐标，实测轮廓锚点；v1–v2 试做已验证，v3 起真实素材替换后 HTML 内不再保留实现）：

- **左肢+锥尖** path：顶 (665,118) → 外缘 (591,164)→(482,263)→(368,361)→(246,460)→(199,509) → 锥尖底 (184,558) → 底缘回扫 (212,607)→(368,656) → 收 (400,640) 闭合。填充线性渐变（左下 `#2f23ff` → 中 `#4a63f5` → 右上 `rgba(150,180,242,.55)`）。
- **右肢+下缘+尾** path：顶 (704,118) → 右缘入画 (1014,213)→(1080,235) 贴边 → 下缘回扫 (1078,673)→(656,630) → 渐细尾 (870,706)→(1078,755) 渐隐闭合。填充渐变（右上 `#3432ed` → `rgba(170,200,245,.5)` → 尾 `rgba(200,220,250,0)`）。
- 透空区：环心 (640–952, 263–460) 不放任何填充——背景渐变直接透出。
- 两 path 各叠一层 `blur(2px)` 柔化玻璃边 + 各自底层复制一份 `blur(28px) opacity .35` 作环境辉光。
- 【硬】飘带区域（y118–755）内禁止出现文字；文字区从 y806 起。

### 7.2 圆角玻璃信息卡（v2 实测配方）

- 圆角 **40**（案例 ~24×1.64，v1 误记 26）；面是 **144° 斜向渐变** `linear-gradient(144deg,#d5e4f9 0%,#c9daf8 50%,#a8c7f6 100%)`——左上与周围 bg 同档、右下明显更深更饱和，靠这个斜向落差成「玻璃体积感」；纵向渐变会显得平（v2 批注修正）。
- 玻璃质感两件套（v5 批注定案）：斜向渐变（主体）+ **顶缘 1px 高光** `inset 0 1px 0 rgba(255,255,255,.55)`（左/下缘 .3/.22 弱一档）。**禁外投影**——体积感全部由斜向渐变落差承担，投影会显得厚重、失「轻薄玻璃」本味（v5 用户批注）。无边框。
- 内 padding 左右 50；正文 25px 黑，行距 49；**正文级强调只用 font-weight 700，不变色**（智能侧边栏、OPPO 互传等）；段间距 30。

### 7.3 强调体系（双层）

- 标题级：品牌蓝 `#0052ff`（效率翻倍），每屏 ≤1 处。
- 正文级：字重 700 黑。
- 禁止第三种强调（下划线/高亮块/橙色等）。

## 8. 调性禁则

1. 【硬】深色面积纪律：全图唯一「重色」是飘带；卡片、文字区禁深底/深字块。
2. 【硬】品牌蓝只用于标题强调词，一屏 ≤1 处；禁作大面积色块。
3. 【硬】文字禁入飘带区（y<800）；飘带禁压文字。
4. 【硬】背景必须是白→浅蓝渐变 + 至多一处软辉光；禁网格、禁噪点颗粒、禁暗角。
5. 【默认】圆角全图统一 40（卡片级）；小元素（徽标/标签）可用 20 半档。
6. 【默认】卡片每段 ≤2 行、全卡 ≤2 段；超量走原型 B 分屏。
7. 【硬】卡片禁外投影（v5 批注：无投影更显轻薄）；hero 素材允许一道柔投影，其余元素禁投影。
8. 【默认】收尾组必须居中；其余全部左对齐——禁两端对齐混排。
