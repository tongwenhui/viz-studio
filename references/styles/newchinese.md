# newchinese · 新中式（A 墨纹 / B 朱砂）

> 一句话：纸纹底 + 宋体大字 + 单左轴排版 + 同色系书法水印（A）；米白纸底 + 朱砂衬线点睛 + 右侧古建插画分栏（B）。
> 家族语言：文人纸感、疏朗留白、直排元素、单一点睛色。两变体共享字体栈与禁则，底色体系与版式骨架不同。

## 1. 画布与安全边距

- **A 展览/讲座海报：1080×1540**（案例 658×939，比例 0.7007≈7:10）。小红书 3:4 出图时用 1080×1440，锚点按 fy 换算
- **B 邀请函：1080×1920（9:16）**（案例 658×1170 即 0.5624），与路由表电子邀请函画布一致
- A 骨架签名：**单一左轴 x=391**——巨字矩阵、展名行、英文副标、「标签/」信息组、票务行全部左对齐此轴；右侧留白 ≈180px 不放内容
- A 底边允许紧凑：票务末行距底边仅 ≈46px（案例实测）；顶部巨字墨迹顶 y≈75
- B 双栏：文字栏 0–0.685W（740px），插画栏 0.685W–W（340px）通高出血；文字安全边距 66px

## 2. 色彩五角色 tokens（全部像素实测）

A 墨纹（单色系，强调靠字重不靠色相）：

```css
:root {
  --c-bg: #4a6051;        /* 墨绿纸底（全图 mode 值；纹理明度起伏 67→82，亮斑 p95≈223） */
  --c-ink: #efebdc;       /* 米白：巨字/展名（笔画核心实测 #fafdef，均值含 AA #e0dacb） */
  --c-ink-dim: #dce0cd;   /* 次级米白：信息组/票务/直排栏 */
  --c-primary: #efebdc;   /* 本变体无第二主色 */
  --c-accent: rgba(255,255,255,0.07); /* 书法水印：叠底后即实测 tint #5d7263 */
  --c-muted: rgba(236,240,225,0.75);
}
```

B 朱砂：

```css
:root {
  --c-bg: #f7f6f1;        /* 米白纸底 */
  --c-ink: #1b1714;       /* 暖墨黑（禁纯黑 #000） */
  --c-primary: #a8400f;   /* 朱砂：西文衬线/胶囊/短线/pin（色带实测 #a63c10–#a63d11，AA 提亮核 #ad6344，取中） */
  --c-accent: #a8400f;
  --c-muted: #979691;     /* 拼音 caps 灰 */
  /* 插画栏取样（用户供图后此组仅作调和参考）：天 #c6aa83 / 墙 #9f6138 / 檐 #60462f / 地 #9f3d16 */
}
```

60/30/10：A = 墨绿底 60 / 米白字 30 / 水印纹理 10；B = 纸底 60 / 插画栏+墨字 30 / 朱砂 ≤5（点睛色，全图 ≤4 处）。

## 5. 网格与间距

- 单左轴 x=391；**fy 锚点（×1540）**：巨字矩阵 0.049–0.374 → 展名行 0.451 → 英文副标 0.492–0.542 → 「展覽日期/」0.632 → 日期值 0.649–0.678 → 時間 0.691/0.708 → 地點 0.744/0.762/0.787 → 票务 0.892/0.925/0.959
- 节奏：巨字区底（y576）与展名行（y695）之间留 119px 呼吸；地址组与票务组之间留 ≈130px
- B 左轴信息流（案例）：主标组 0.13–0.30 → 活动名 0.415 → TIME 组 0.60–0.68 → 短线 0.70 → 地址 0.72 → 结语 0.78–0.82
- 段距纪律：信息组之间 ≥60px；同组内标签与值紧凑（≤10px）

## 6. 布局原型

- **P1 展览/讲座海报**（A 案例）：巨字矩阵(4 字) → 展名+英文副标 → 三段「标签/值」信息组 → 票务行压底
- **P2 邀请函**（B 案例）：左轴标题组（中文主标+西文衬线+[方括号行]+胶囊）→ 活动名 → TIME/地址 → 结语；右侧插画栏通高
- **P3 直排变体**：巨字改直排右起双列，信息栏右移，右缘留白换到左侧
- 要点 >6 组：复制「标签/值」段向下排，**禁止加卡片底色/图标**；再多为改 data-graphic

## 7. 组件语言

- **巨字矩阵**：4 字 2×2 按行读（案例「茶颜/韵色」），是本族签名元素；墨迹顶可贴 y≈75，与左轴对齐
- **「标签/」信息组**：小标签带全角斜杠尾 + 46px 粗值；禁图标、禁横线分隔（B 红短线除外）
- **直排单位栏**（A）：`writing-mode: vertical-rl`；标签列 + 单位名列成组，字距 0.75em 极疏朗；段间 1px 竖线 tick（高 ≈90px，cream 35%）；底部微字三列 13px 诗行 + 旁侧 1px 细线
- **书法水印**：漓雨手书 rgba(255,255,255,0.07)，双字对角布位（左上、右下各一，部分出血画外），z 序在纸纹之上、文字之下
- **纸纹配方**：SVG feTurbulence fractalNoise（baseFrequency ≈0.8，去饱和）平铺 + `mix-blend-mode: soft-light` + 边缘 vignette（rgba(20,32,24,0.18)）；纹理作用于全图含文字（案例如此）
- **B 胶囊**：朱砂底白字，radius 8px，高 ≈57px，字距 0.2em
- **B 红短线**：384×6px 朱砂实线（案例 234×4px×1.641）
- **B 插画栏**：仅用户供图/授权图库；**案例右栏带图库水印，禁止直接复制**；CSS 兜底用 §2 四色分层平面构成且显式标注占位

## 8. 调性禁则

1. A 禁第二色相——全图只有墨绿+米白两级，层级靠字号字重不靠颜色
2. 水印对比上限：与底明度差 ≤8%（实测 alpha 0.07）；水印禁压正文可读区
3. 禁纯黑 #000/纯白 #fff：墨 #1b1714 起，纸白 #f7f6f1 起
4. 朱砂（B）只作点睛：全图 ≤4 处（西文衬线、胶囊、短线、pin）
5. 字距纪律：巨字 0.04em、标签 0.18em、直排单位 0.75em、正文 ≤0.08em；中文禁全大写化排版
6. 直排栏渲染后必检：标点直立（`text-orientation: mixed` 下引号/破折号）、列序、溢出
7. 禁现代几何装饰（渐变球/光效/圆点阵列）——质感只来自纸纹+书法水印+宋体
8. 用户反参照压过本册一切默认
9. **施工铁律**：absolute 定位的组容器（如信息组）必须显式 `width/height`——子元素全 absolute 时 shrink-to-fit 塌陷为 0 宽，文本逐字折行呈"假竖排"（v1 试做实翻车）；纯排元素（巨字/展名/票务）可直接挂画布坐标不经组容器
