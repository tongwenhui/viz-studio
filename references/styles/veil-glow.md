# veil-glow 光影纱幕 · 风格分册

> 一句话：全幅柔焦氛围底当舞台，白色/朱红衬线大字沿中轴缓缓落下——邀请函与峰会竖版 KV 的仪式感语言。
> 来源：case-01 红纱「邀」（A）/ case-02 墨绿「逐光而来」（B），2026-09 像素实测蒸馏。状态 **v2 定稿（2026-10-12 用户整体过会）**。
> 叠加遵守 `guardrails.md`，冲突时按其 §10 优先级。所有 hex 为当日实测值。

## 变体总览

| 变体 | 底色语言 | 排版轴 | 适用 | 信息量 |
|---|---|---|---|---|
| A 朱红银纱 | 上银天 + 下红绸 + 朱红字 | 居中轴 + 底部双栏信息区 | 峰会/年会邀请函、活动请柬、婚庆 | 主题词 + 书法大字 + 地点时间 + 流程 |
| B 墨绿光斑 | 全幅模糊绿影照片 + 白字 | 居中单轴，纯纵向节奏 | 品牌邀请函、讲座宣发、金句卡 | 引言 + 巨题 + 祝福 + 诗行 + 地址 |

适配格式：电子邀请函（原生）、竖版 KV/手机整屏 H5 头图、易拉宝迎宾面（延展）；公众号/小红书封面**慎用**（比例不合需重构，氛围底可迁移）。

---

## 1. 画布与安全边距

- 原生画布 **1080×2340（9:19.5 手机整屏）**；走邀请函路由 1080×1920 时按 §5 的百分比锚点纵向压缩，不裁内容。
- 【硬】左右安全边距 ≥76px（7%）；首尾留白：首块内容 y ≤13%、末块内容 y ≥87% 起。
- 【硬】纱幕底必须全幅出血，四边无框、无卡片、无描边容器。
- 【硬】文字只落在静区（见 §8.1），光带最亮处禁止叠正文。

## 2. 色彩五角色 tokens

### A 朱红银纱（case-01 实测）

```css
:root {
  --c-veil-top: #e8e9ec;    /* 银天顶部冷灰（实测） */
  --c-veil-mid: #faf6ee;    /* 天空中段暖白（实测 #faf7f0） */
  --c-glow: #f3d5c8;        /* 地平线暖粉辉光（实测 #f9cdbd~#e1c8c7 取中） */
  --c-silk-deep: #c01208;   /* 红绸最深（实测 #c60000→应用提亮） */
  --c-silk-mid: #d0301f;    /* 红绸主体（实测 #ce2826） */
  --c-silk-light: #e97864;  /* 底缘珊瑚渐亮（实测） */
  --c-accent: #f43b16;      /* 朱红字（实测 #fa3e10→抗锯齿补偿） */
  --c-brush: #ef1f06;       /* 书法大字红（实测 #f51b01） */
  --c-paper: #ffffff;       /* 幽灵英文 / 信息白字 */
}
```

面积比：55 银天 / 35 红绸 / 10 朱红字。【硬】全图只有「红」一个色相家族：银天是无彩底，朱红只用于字与书法；禁出现第二个色相。

### B 墨绿光斑（case-02 实测）

```css
:root {
  --c-veil-deep: #0f1d0c;   /* 绿影最深（实测 #0a1807） */
  --c-veil-mid: #24331f;    /* 暗绿主体（实测 #21271e / #1e311c） */
  --c-veil-lift: #4d5c3e;   /* 亮部橄榄绿（实测 #466141 / #5c6441） */
  --c-glint: #ab8851;       /* 暖黄光斑（实测，微量点缀） */
  --c-text: #ffffff;        /* 全部文字 */
  --c-text-soft: rgba(255,255,255,.82);  /* 次级行 */
}
```

面积比：90 绿影 / 10 白字。【硬】B 无强调色，白字只靠字重与字号分层；暖黄光斑只属于底图层，禁用于文字。

## 3. 字体栈

| 职 | 选型 | 说明 |
|---|---|---|
| 衬线主题字 / 正文 | 思源宋体 Noto Serif SC VF（200–900 真字重，OFL） | A/B 全部中文字的基座；主题词 700，正文 500，微字 400 |
| 书法大字 | 漓雨手书 Liyu Shoushu Regular（OFL，毛笔楷书） | 库内唯一真实笔锋书法体，潇洒飘逸；原案例为湿笔书法，此为最接近选型。文楷 + 10–12px stroke 增重仅作字体缺失时兜底 |
| 幽灵英文 / 装饰行 | EB Garamond Regular（OFL） | 原案例为高对比时装衬线（Didot 系），Garamond 为项目内在替代，全大写 + 大字距 |

- 离线加载：`fonts/source-han-serif/NotoSerifSC-VF.ttf`、`fonts/liyu-shoushu/LiyuShoushu.ttf`、`fonts/english-eb-garamond/EBGaramond-Regular.ttf`，相对路径 `@font-face`，禁 CDN。
- fallback：衬线 `'Noto Serif SC','Songti SC',serif`；书法 `'Liyu Shoushu','LXGW WenKai','Kaiti SC',serif`；英文 `'EB Garamond','Didot',serif`。
- 【硬】书法大字一图至多一个词（≤4 字）。
- 【默认】书法大字用真笔锋字体时禁加 `text-stroke` 增重（会糊掉飞白）；笔锋字体光学尺寸偏小，字号按 §4 上沿取。
- 【默认】中文不使用斜体/变形；英文装饰行一律大写。

## 4. 字号阶（1080 宽画布，px）

| 层 | A 朱红 | B 墨绿 |
|---|---|---|
| 幽灵英文（全宽出血） | 120–140，ls .18–.22em | — |
| 引言（含「」） | — | 34–38，ls .1em |
| 主题词（邀请函等） | 72–80，ls .5em+ | — |
| 巨题（B） | — | 130–150，ls .08em |
| 书法大字 | 560–660（单字，真笔锋字体取上沿） | — |
| 副题 | 54–58，ls .3em | — |
| 祝福/正文行 | — | 32–36 |
| 诗句块 | — | 34–38，行高 1.9 |
| 拼音/英文装饰行 | — | 20–24，ls .45em，opacity .75 |
| 信息标签 | 28–30 | — |
| 信息值 | 38–42，500–600 | — |
| 流程标题 | 50–54，ls .12em | — |
| 时间轴行 | 32–36，行高 2.1 | — |
| 尾部字距行（Z H U…） | — | 24–28，ls .9em |

- 【硬】主题词与副题的字距 ≥.3em（仪式感来源）；正文信息区恢复常规字距 ≤.05em。
- 【硬】书法大字与副题字号差 ≥9 倍——大字是画面，副题才是信息。

## 5. 网格与间距

- 居中单轴：全部主题层水平居中；版心宽 928px（1080−2×76）。
- **纵向锚点用画布高百分比记录**（换画布比例时按锚点重排）：
  - A：幽灵英文 8–13% → 主题词 16–20% → 书法大字 21–46%（视觉中心 34%）→ 副题 50–52% → 信息区 73–93%。
  - B：引言 7–10% → 巨题 28–38% → 祝福行 43–46% → 分隔符 52% → 诗行 59–70% → 字距行 80% → 地址 87–89%。
- A 信息区双栏：左栏（地点/时间）占 38%，右栏（流程）占 54%，栏距 8%；两栏顶对齐。
- 8pt 基线；行间距普遍 1.9–2.2 倍（纵向节奏是本风格的呼吸来源，禁压紧）。

## 6. 布局原型（按要点数）

| 要点数 | 原型 | 说明 |
|---|---|---|
| 1 词 + 极少信息 | B | 引言 → 巨题 → 祝福 → 地址，全居中 |
| 主题 + 时间地点 + 流程 | A | 幽灵英文 + 主题词 + 大字 + 副题 + 底部双栏 |
| 峰会/年会竖版 KV | A | 同上；流程列改嘉宾阵容或议程亮点 |
| 婚庆/请柬 | A/B 均可 | 流程列换「仪式/晚宴」；B 换用户提供底图 |
| 金句卡 | B | 引言即金句，巨题换成关键词 2–4 字 |

## 7. 组件语言

**纱幕底 A（纯 CSS 配方，四层）**：
1. 天空：`linear-gradient(180deg, #e8e9ec 0%, #efedea 24%, #f7f1e6 40%, #f6e3d3 52%, #eec7bb 58%)` 铺上半；
2. 红绸：y 52% 起 `linear-gradient(175deg, #e9b9ac 0%, #d0301f 16%, #bb0f08 36%, #cf2f1e 56%, #e2503a 78%, #ea7a66 96%)` 铺下半；
3. 绸面横纹：两层 `repeating-linear-gradient(180deg, 透明 0 26px, rgba(255,255,255,.14) 26px 30px, 透明 30px 56px, rgba(90,0,0,.18) 56px 62px)`，周期一 46px 一 83px 错开规律感，`filter: blur(7px)`；
4. 亮银光带：信息区上方 y≈76% 一条高 80–100px 的 `linear-gradient(90deg, transparent, rgba(255,255,255,.75) 20% 80%, transparent)` + `blur(16px)`——原案例的银缎高光。
5. 可选柔焦斑：两团 8% 白色大 radial 光斑增加纵深。

**纱幕底 B**：模糊照片优先（用户提供，`filter: blur(0px) saturate(.9)` 直接用原图的虚化感）；无图时 CSS 兜底——3–4 团 `--c-veil-lift / --c-veil-deep` 的大 radial 光斑 + 一层斜向 `repeating-linear-gradient` 细条纹（2px 周期，opacity .06）+ `blur(2px)`，模拟失焦叶影。禁纯色平底。

**幽灵英文层**：EB Garamond 大写，全宽出血（允许左右各溢出 2%），`color: rgba(255,255,255,.6)`；B 变体不用幽灵层，改用「巨题背后的细字距英文行」（叠在巨题下缘，opacity .5）。

**书法大字**：漓雨手书（Liyu Shoushu），裸字不描边；颜色 `--c-brush`；禁加投影、禁渐变字、禁倾斜。字体缺失时兜底：文楷 + `-webkit-text-stroke: 11px currentColor` 增重。

**时间轴**（A 流程列）：标题「活动流程」→ 4 行以内；每行 = 圆点（10px 白，实心）+ 竖连线（1px `rgba(255,255,255,.55)`）+ 文字；行距 2.1 倍；时间与事项同行，空一格分组，不再分层。

**信息双栏**（A）：标签 `[地点ADD]` 方括号原文保留，`rgba(255,255,255,.85)` 400；值白色 600。文字可加极轻投影 `0 2px 14px rgba(110,10,0,.28)` 保 silk 上的可读性。

**分隔符**（B）：单颗「✳」字形，28px，opacity .8，禁用线条分隔。

**字距行**（B 尾部）：`Z H U G U A N G E R L A I` 手动加空格或 ls .9em，是 B 的签名装饰。

## 8. 调性禁则

1. 【硬】文字只落静区：白字落在纱幕最暗/最模糊处，红字落在银天最亮处；任何正文不得压在亮银光带上。
2. 【硬】A 只有一个色相家族：银天无彩、红绸与红字同族；禁蓝紫绿等第二色相，禁金/棕介入（那是 silk-flare 的领地）。
3. 【硬】幽灵英文永远退后：opacity ≤.7、无描边无阴影、不做前景信息；装饰行的存在感 ≤ 巨题的一半。
4. 【硬】超大字一图一个词（≤4 字）；禁成句书法、禁多字竞大。
5. 【默认】纵向行距 1.9–2.2 倍，首尾留白 ≥13%/13%；禁把信息区顶到边缘。
6. 【默认】B 必须有全幅失焦底；禁纯色、禁几何图形、禁卡片容器。
7. 【默认】强调色预算：A 的朱红只出现在主题词/副题/书法字 ≤3 处；B 零强调色。
8. 【默认】英文装饰行一律全大写 + ≥.4em 字距；禁小写、禁句点。
9. 用户反参照置顶（guardrails §10.1）。
