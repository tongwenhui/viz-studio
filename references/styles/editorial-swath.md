# editorial-swath · 材质编辑风（深绿底 × 材质摄影卡）

> 一句话：平涂深绿底上浮一张满铺材质摄影的竖卡，全部排版压在卡上——衬线贯穿、括号族装饰、近黑大标 + 森林绿中文、卡下白字收尾。

## 变体总览

| 变体 | 案例 | 特征 |
|---|---|---|
| A 材质卡（本册主体） | case-01 WAKE UP SPRING | 白色褶皱膜 × 绿水面材质卡，双段平涂底 |

## 1. 画布与安全边距

- 画布 **1080×1440（3:4）**，案例 658×875（k=1.6413）。
- 竖卡：x238–855（宽 617）、y62–1382（高 1320），水平居中；上边距 62、下边距 58（近满高悬浮）。
- 卡投影：`0 18px 60px rgba(0,0,0,.35)` 级别的柔和暗影，禁止硬边。
- 安全区：卡内文字距卡缘 ≥ 25px。

## 6. 布局原型

单卡浮层式（全要点居中型）：双段平涂底 → 居中竖卡满铺材质摄影 → 文字全部压卡，居中轴为主轴；仅页眉两列、卡底微字、箭头偏离主轴。适合「一句主张 + 一句系列名」的轻内容物料；要点 >5 组时本原型不适用，换分册待补的 Multi 原型。

## 7. 组件语言

- **材质卡（核心资产）**：优先级 实拍材质图（用户供/图库）> AI 生成材质（交付需声明）> CSS 兜底。试做当前为 CSS 兜底：膜区 = 浅底 + 大尺度斜向柔光褶皱（多层 linear/radial-gradient + blur）+ `feTurbulence fractalNoise` 两层叠加（soft-light/screen）做细褶；水区 = 深绿底 + `baseFrequency="0.002 0.08"` 拉伸噪波做横纹 + 右侧中部一块更深的绿楔从卡右缘切入（y≈740–830）。
- **括号族**：三种括号承担三级节奏——〔〕（页眉中文题）、｛｝（英文两行组）、（）＋高瘦全角括号（中文主张行）。星号 `*` 只做主标第二行首尾对称装饰。
- **省略号 ⋯**：主张区与英文区之间的独立停顿行，居中。
- **字距展示级**：`2025 / NEW` 与 `早春系列` 用大字距做「陈列柜」效果，是全卡唯一两处大字距。
- **箭头**：细线「↘」= 45° 斜线 + 右/下两边直角边，stroke 2px。
- **底色接缝**：上下两段平涂在画布 y≈1001 硬切，位置≈卡高的 71%，与卡内水域起点呼应。

## 8. 调性禁则

1. 【硬】卡必须满铺材质摄影，禁止纯色/渐变卡。
2. 【硬】底是平涂双段，禁止渐变、禁止加纹理；接缝是硬切。
3. 【硬】全卡衬线贯穿，禁止无衬线混入。
4. 【硬】原案例英文为拼贴乱码（WAKE UPIN / ACHVHY / SPRINGRESERVATION），生产必须替换用户真实文案，禁照抄。
5. 绿字（forest-ink）只允许两处：中文括号块、LET 行；主标必须近黑。
6. 白字只出现在卡下水域区（2025/NEW、早春系列、卡底微字、箭头），禁止白字压膜。
7. 装饰限额：括号族 + 星号 + 省略号，共四类，禁止再引入图标/线条框。
8. 大字距仅限 2025/NEW 与早春系列两处，主标正常字距。
9. 要点 ≤5 组；超出换原型，不硬塞。

## 10. 落地技术注记（试做校准实测）

- EB Garamond 57px 的 "WAKE UPIN SPRING" 自然宽 ≈ 540px，占卡宽 0.88；对齐案例占宽（≈0.97）需 `letter-spacing:0.5px` 微调，禁 `white-space:nowrap` 出卡。
- 材质图替换 CSS 兜底时：`object-fit:cover` + `object-position:top`，容器 `overflow:hidden`；先读图的真实宽高比再定容器，禁止拉伸。
- 媒体生成通道未配置（API key 缺失）时按本册 §7 CSS 兜底执行，交付说明里声明。
