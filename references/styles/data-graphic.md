# data-graphic 数据图形 · 风格分册

> 一句话：让数字当主角——巨数 + 模块化网格，图表只做数字的证明。财报 / 产品数据页 / 数据长图 / 数据卡的默认语言。
> 来源：case-01 小米财报（A1）/ case-02 NP Digital（A2）/ case-03 HyperOS 暗夜（B）/ case-04 Yandex 彩卡（C），2026-09 像素实测蒸馏。状态 **v1 定稿（2026-09-21 用户过会）**。
> 叠加遵守 `guardrails.md`，冲突时按其 §10 优先级。所有 hex 为当日实测值。

## 变体总览

| 变体 | 底色语言 | 排版轴 | 适用 | 信息量 |
|---|---|---|---|---|
| A1 浅色财报 | 暖浅灰 + 黑字 + 单强调橙 | 左对齐单轴 | 财报 / 业绩速报 / 数据长图 | 2 组 KPI + 1–2 图表 |
| A2 浅色品牌数据页 | 浅灰 + 深青黑标题 + 单强调橙 | 居中轴 | 品牌介绍 / 数据名片 / 服务页 | 标题 + 视觉主体 + 四栏统计 |
| B 暗夜大数字 | 纯黑 + 渐变巨数 | 居中单轴，分组 | 发布会参数页 / 对比数据 / PPT 数据页 | 2–3 组 × 2–3 数 |
| C 彩卡拼贴 | 暗底光斑 + 彩色卡片马赛克 | 卡片网格（横版） | 数据海报 / 社群数据 / 年报摘要 | 6–10 张卡 |

---

## 1. 画布与安全边距

- A1 财报 / B 暗夜：1080×1440（3:4，scale 2 导出）；A2 品牌数据页：1080×1620（2:3）。
- C 彩卡：1920×1240（横版 ≈14:9，case-04 实测比例）；数据长图延展 1080×2400+，每屏一组 KPI。
- 【硬】四边安全边距：1080 画布 ≥72px；C 画布 ≥56px；图表与文字永不贴边。
- 【硬】图表区域不与文字重叠；每张图表自带标签层，不依赖画布外说明。

## 2. 色彩五角色 tokens

### A1 / A2 浅色（case-01 / case-02 实测）

```css
:root {
  --c-bg: #f3f3f3;          /* 暖浅灰底，实测四角 */
  --c-ink: #0a0a0a;         /* 标题黑，实测 #030303 → 应用提一档 */
  --c-label: #1a1a1a;       /* KPI 标签 / 正文 */
  --c-muted: #666666;       /* 副说明、轴标签次级 */
  --c-primary: #fa4d00;     /* 数据橙：巨数 / 图表线 / 同比值（实测 #ff4d00~#fa4d00） */
  --c-brand: #ff6900;       /* 品牌橙：仅 logo 色块（实测 #fe6902），不进数据层 */
  --c-navy: #141f23;        /* A2 标题深青黑（替代纯黑，实测） */
  --c-map-dot: #bdbdbd;     /* A2 点阵地图（实测） */
  --c-chip: #fefefe;        /* A2 白卡 / 控件底 */
}
```

面积比：60 浅底 / 30 黑字 / 10 橙。【硬】A2 标题用 `--c-navy` 不用纯黑（实测区分）；A 变体橙是唯一彩色。

### B 暗夜（case-03 实测）

```css
:root {
  --c-bg: #000000;          /* 纯黑 */
  --c-ink: #ffffff;
  --c-caption: #b5b5b5;     /* 数字下说明行（实测） */
  --c-fine: #8a8a8a;        /* 底部免责微字 */
  --grad-blue-a: #2791f5; --grad-blue-b: #54e1f5;   /* 蓝青族，左深右亮（实测） */
  --grad-green-a: #48e29c; --grad-green-b: #6df370; /* 绿族（实测） */
  --c-brand: #1c57fd;       /* 品牌词着色字（实测 HyperOS 的 OS） */
}
```

【硬】B 变体渐变只许蓝青族 / 绿族（按组分配，一组一色族），禁红紫渐变数字；渐变方向固定 `90deg` 左深右亮。

### C 彩卡（case-04 实测）

```css
:root {
  --c-field: #241422;       /* 暗紫底基色，叠酒红/紫蓝模糊光斑（实测 #231316 / #43283a / #261c73） */
  --card-orange: #fe5416;   --card-white: #f0f1f5;   --card-green: #009366;
  --card-purple: #5237e8;   --card-black: #000000;   --card-pink: #ea94d5;
  --bar-green: #029368;     --bar-orange: #fd5413;   /* 白卡内 mini 条形图 */
}
```

【硬】C 的卡片色即数据色：白字只上深色卡（橙/绿/紫/黑），黑字上白/粉卡，每卡一种文字色；卡片之外（底色层）不出现彩色文字。

## 3. 字体栈

| 职 | 全变体通用 |
|---|---|
| 标题 / 巨数 | 思源黑体 Noto Sans SC VF（wght 400–900 真字重，OFL）；巨数 700，巨题 900 |
| 正文 / 标签 | 同族 400/500，`font-variant-numeric: tabular-nums` 全局开 |
| 品牌词 | 同族 700，可单字着色（B 变体 `--c-brand`） |

- 离线加载：`fonts/source-han-sans/NotoSansSC-VF.ttf`，`@font-face` 相对路径引入，禁 CDN。
- fallback：`'Noto Sans SC','MiSans','PingFang SC',system-ui,sans-serif`。
- 【硬】数字永远是同族最重字重（700），禁用细字重当巨数；禁衬线、禁手写体混入（数据语言的族内纯度）。

## 4. 字号阶（按画布基准）

| 层 | A1（1080×1440） | A2（1080×1620） | B（1080×1440） | C（1920×1240） |
|---|---|---|---|---|
| 眉题/meta | 32–34 | — | — | — |
| 主标 | 巨题 130–150 两行 | 64–72 居中 | 组题 54–60 两行 | —（卡是主角） |
| 副文 | — | 28–30 | — | — |
| KPI 标签 | 30–32 | 22–24 大写两行 | — | 卡内标签 26–30 |
| 巨数 | 150–170 | 72–80 | 170–200 | 主数 110–150 / 中数 64–88 / 小数 32–40 |
| 单位 | 46–52（≤巨数×0.33） | — | 角标 % 56 | 卡内注 24–28 |
| 说明行 | 同比 33–35 | — | 30（`--c-caption`） | — |
| 图表标签 | 值 26 / 轴 23–24 | — | — | mini bar 值 24–28 |
| 免责/来源 | — | — | 16–18（`--c-fine`） | — |

- 【硬】巨数与说明行字号差 ≥3 倍；单位 ≤ 巨数 ×0.33 且基线对齐。
- 长图延展（1080×2400+）：每屏字号沿用 A1 阶，屏间用小节标题分隔。

## 5. 网格与间距

- A1 **左对齐单轴**：边距 76px；meta → 巨题 → KPI 双栏 → 小节标题 → 双图表，纵向节奏 64–88px 一档。
- A1 KPI 双栏：各占 44% 宽、列距 8%；图表双栏同构（各 42%，列距 6%）。
- A2 **居中轴**：全部水平居中；四栏统计等宽 + 1px 竖分隔线（#ddd）；统计区上方留白 ≥120px。
- B **居中单轴分组**：组1 占 y 12%–40%，组2 占 48%–78%，品牌行 86%，免责行 95%；组内数字行居中排布、间距 100–120px。
- C **卡片网格**：3 列不等宽（≈30% / 34% / 28%），gap 40px，圆角 44px 全图统一；卡片高度按内容，行间对齐网格不留半卡。
- 8pt 基线；所有巨数 `tabular-nums`。

## 6. 布局原型（按要点数）

| 要点数 | 原型 | 说明 |
|---|---|---|
| 2–4 个 KPI | A1 | 双栏 KPI + 可选双图表；>4 组转 C |
| 标题 + 主体 + 统计 | A2 | 控件行 / 视觉主体（地图等）/ 四栏统计 |
| 2–3 组对比数据 | B | 每组：白题两行 → 2–3 个渐变巨数 → 灰说明 |
| 6–10 条事实 | C | 一卡一事：小标签 + 巨数 + 小注；事实多卡小、事实少卡大 |
| 混合财报 | A1+C | 顶部 KPI 双栏，下半转彩卡区（横版数据海报） |

## 7. 组件语言

**KPI 巨数**（A）：标签黑 500 → 巨数橙 700 + 单位橙 600（基线对齐，margin-left 8px）→ 同比行「标签黑 + 值橙 600」。数字用 `--c-primary`，单位禁黑。

**渐变面积图**（A1，SVG 实现）：
- 折线 4px `--c-primary`，`stroke-linejoin: round`；
- 闭合 polygon 填充 `linearGradient`（#fa4d00 .22 → 0，垂直向下）；
- 数据点：r6 白芯 + 3.5px 橙描边；
- 【硬】每个点必须有数值标签（26px 橙 600，点上方）+ 类目标签（轴行 23–24px #333）；两点间不插标签、不许标签互相重叠或被裁切；
- 比例必须由真实数据计算（y = f(v)，写在注释里），禁目测坐标。

**下箭头 %**（B）：巨数右上角 % 角标（56px，同渐变色），数字右侧垂直渐变下箭头（SVG，杆+三角，同色族渐变）——「下降」语义，上升改上箭头，禁无方向裸数字。

**点阵地图**（A2 可选模块）：dot-matrix 世界地图，dot 4px `--c-map-dot`、间距 12px；活跃城市用定位 pin（`--c-primary`，带白芯）；可叠白浮卡（#fff，radius 14，shadow `0 8px 24px rgba(0,0,0,.10)`）标注单点。

**圆形图标位**（A2）：96px 圆，底 `rgba(250,77,0,.10)`，线性图标 `--c-primary` 2px 描边。

**四栏统计**（A2）：图标位 → 巨数 700 → 两行大写标签；栏间 1px #ddd 竖分隔。

**彩卡**（C）：radius 44、padding 32–40、无边框无阴影（暗底靠色块分界）；卡内结构：顶部小标签（600）→ 巨数 700 → 小注（opacity .85）；白卡可嵌 mini bar chart（3–4 条，圆角短条，高按 `--v/--max` 真实计算，值标签在条上方，类目在条内或下方）；黑卡反白。同一张卡内禁第二层嵌套卡片（mini bar 是图形不是卡）。

**品牌行**（B 尾部）：品牌词 52px 白 700 + 着色后缀（`--c-brand`）；下缀中文小字 28px `--c-caption`。

## 8. 调性禁则

1. 【硬】数据诚实：图表每点/条必须带类目 + 数值标签；比例由真实数据计算，禁目测、禁装饰性假数据。
2. 【硬】A 变体橙是唯一彩色，全图 ≤5 处（巨数、单位、同比值、图表层、logo）；其余黑白灰。品牌橙 #ff6900 只进 logo 色块，与数据橙分工不混用。
3. 【硬】B 渐变只许蓝青族 / 绿族、方向固定 90deg；一组数字一个色族；禁红紫、禁彩虹、禁数字带描边。
4. 【硬】C 卡片文字对比成对：白字只配深卡、黑字只配浅卡；卡片外底色层禁彩色文字。
5. 【硬】巨数 `tabular-nums` + 最重字重；单位 ≤ 巨数 ×0.33；巨数与说明字号差 ≥3 倍。
6. 【默认】A1 KPI 双栏 ≤2 栏；数据组 ≥3 转用 B 或 C 语言，不硬塞双栏。
7. 【默认】免责/来源微字：深底 #8a8a8a、浅底 #999，字号 ≥16（1080 画布），贴底但不与内容争层级；财报类必带「数据来源」行。
8. 【默认】C 网格 gap 与圆角全图统一；卡片圆角 44px（1920 画布）不随卡片大小变化。
9. 【默认】留白纪律：巨数四周 ≥56px 净空；禁在数字区叠光效、纹理、渐变底（B 的黑就是黑）。
10. 用户反参照置顶（guardrails §10.1）。
