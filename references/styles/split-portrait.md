# split-portrait · 半版人像海报

> 蒸馏源：`case-01-xtb.png`（1080×1440，XTB 金融社媒图）。
> 一句话：**近黑噪纹底 + 右半出血人像融入黑暗 + 亮蓝几何折件锚在分界线上 + 白色巨型标题越线压图**。人像占半壁、蓝色只做刀口。

## 1. 画布与安全边距
- 画布 1080×1440（3:4 竖版）。
- 安全边距：左右 57px（≈5.3%W）；顶部 logo 基准 y=54（3.75%H）；底部免责最后一行基线距底 ≈57px（4%H）。
- 人像满出血：贴右、上、下三边；分界线 x=540（50%W）为构图轴，但不画线——由蓝色几何件与明暗交界暗示。
- 照片左缘不做硬边：用暗部渐隐融入背景（上半段借烟霭过渡，下半段西服黑即背景黑）。

## 2. 色彩角色表
| 角色 | 值 | 用法 |
|---|---|---|
| 底黑 | `#0a0a0a`–`#121212` | 全画布基底，随烟霭微浮动 |
| 烟霭灰 | `#2e2e2e` → `#5c5c5e`（最亮） | 左上象限软性烟团（bbox x64–556, y0–896），左下角带蓝灰光晕 |
| 人像 | 全彩但暗调、低明度 | 右半，暖肤色为唯一大面积暖源 |
| 点睛蓝 | `#1070F8` | 仅几何折件：顶部实心楔形 + 右侧折带。全图唯一高饱和色 |
| 文字白 | `#ffffff` | logo 盒、kicker、巨型标题、免责 |
| 墨黑 | `#0b0b0b` | logo 白盒内的 X 标 |

铁律：蓝件面积 < 8% 画布；除蓝外全图无第二彩源（人像肤色除外，且整体压暗去艳）。

## 3. 字体栈
- 单一无衬线家族：案例为几何无衬线（Poppins 类，单层 g）。替代栈：**Roboto Flex VF**（`fonts/english-roboto-flex/RobotoFlex-VF.ttf`，@font-face `font-weight: 100 1000`），标题 wght≈500–600，正文 400。中文字形由 Noto Sans SC VF 兜底。
- 标题微收字距（-0.01em 级）；kicker/免责正常字距。
- 数字直接用同家族 lining。≤2 款字体，本族天然满足。

## 4. 字号阶（1080×1440 实测，H=1440）
| 层级 | 字号 | 行高 | 案例 |
|---|---|---|---|
| 巨型标题 | ≈126px（cap 90px） | 单行 | "Ketangguhan" y950–1067（含降部），x63→860 |
| kicker 引语 | ≈36px | — | "Kunci Investor Sukses:" y869–905 |
| 免责/脚注 | ≈28px | 36px（1.3） | 4 行 y1252–1383 |

## 5. 网格与锚点
- 左轴 x≈57–63：logo、kicker、标题、免责全部左对齐同一竖轴。
- 垂直节奏：logo 带 y54–133 → 大留白 → kicker y869 → 标题 y950 → 免责 y1252。中段 700px 全给人像。
- 分界轴 x=540：蓝色几何件全部咬合此轴（楔形直角边、折带穿越点）。

## 6. 布局原型
```
┌──────────┬───────────────┐
│ logo盒+字 │               │
│   烟霭◤  │   人像(出血)   │ ← 顶部实心蓝楔 (370,0)-(544,0)-(540,150)
│          │  面部 y212-780 │
│          │               │ ← 右侧蓝折带 x≈1005→960 (y390-1160)
│ kicker   │               │
│ 巨型标题━━━━━━━━━━━━━━→ │ ← 标题越线压图 (x63→860)
│          │               │ ← 折带转弯(≈975,1160)斜切至底缘 x≈400
│ 免责×4行 │               │
└──────────┴───────────────┘
```
- 标题是唯一允许越过分界线的文字元素；kicker 与免责不得越线。
- 蓝色折带在底部从人像身上斜切而过，把视线收回左下免责区。

## 7. 组件语言
- **logo 盒**：80×80 白色方块（圆角≈4px）内含黑色抽象 X 标，右侧接白色小写 wordmark；整组贴左上锚点。
- **蓝色楔形（顶）**：实心 `#1070F8` 直角三角形，直角边贴分界线（x=540, y0–150），斜边从 (370,0) 收至 apex (540,150)，像刀口劈开画面顶部。
- **蓝色折带（右+底）**：粗 ≈45px 实心折线：上段近垂直（x≈1005@y560 → x≈960@y1140，微左倾），在 ≈(975,1160) 转折，下段以 ≈23° 俯角向左下斜切，跨过分界线于 y≈1390，出底缘于 x≈400。折带压在人像之上。
- **烟霭**：2–3 个大半径软渐变斑（灰 `#5c5c5e` 级）叠在左上；左下角一枚蓝灰冷光晕。全部低对比、无边界的空气感。
- **胶片颗粒**：全画布重颗粒（1–2px 单色噪点，视觉幅度 ±25–35/通道），暗部亮部均可见——本族的材质签名，不可省。
- **人像处理**：全彩但整体压暗、低饱和倾向；左缘用 mask 线性渐隐入黑；无描边、无投影、无相框。

## 8. 调性禁则
1. 禁止给分界线画实体线/分栏底色——分界只靠蓝色几何件与明暗暗示。
2. 禁止第二高饱和色；蓝色件总面积 ≤8% 画布，且只允许「楔形 + 折带」两类刀口形态。
3. 巨型标题必须越线压图（宽度 ≈74%W，跨分界 ≈320px）；其余文字禁越线。
4. 人像禁硬边、禁相框、禁投影；必须暗调融入背景。
5. 禁省略颗粒纹理；禁把底色提亮超过 `#1a1a1a`（烟霭峰值除外）。
6. 禁把标题换成衬线/手写体——本族唯一字体气质是几何无衬线。
7. 免责等脚注字号 ≥24px、行高 1.3、行数 ≤4。
