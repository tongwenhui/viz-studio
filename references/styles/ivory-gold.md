# ivory-gold · 象牙金（米白 × 铜棕衬线 × 金沙插画）

> 一句话：暖米白纸面上居中排列的铜棕衬线字阶（轻 Didone 巨字 INVITATION + 高瘦宋体「邀请函」被一行陶土红细拼音横穿），下接胶囊细框与竖发丝线信息层，底部去底马匹素材（现行：用户供图鎏金水墨**奔马**，~800px 高近全幅横贯、无投影）立于金沙渐变上——「礼遇请柬」气质；B 变体为左对齐峰会海报，右下金色玻璃扇面几何张开放。

## 1. 画布与安全边距

- **A**：画布 **1080×2340（9:19.5 手机整屏）**，案例 658×1424（k=1.6413）。
- **B**：画布 **1080×2160（1:2）**，案例 950×1900（k=1.1368）。
- 等效画布：A 可压 3:4 邀请卡（§6 原型 B）；B 可放 2:3 海报。
- 安全边距：A 全部内容居中轴 x=540，正文横向不超出 x120–960；B 左对齐轴 x=75，右侧扇面区 y>1000 净空。
- 底色：A `#faf7f0`（顶缘 `#eeefe4` 渐入）；B `#fdfaf5` 平涂。两变体均为「纸面」暖白，禁纯白。
- 【真单裁定 2026-10-10】A 生产画布锁定 **1080×2340**，路由表默认 1080×1920 仅作无本分册时兜底：1920 下 ≥700px【硬】马体与巨字塔无法两全（塔尾与马首间隙 <30px，比例全毁）；命中本风格时画布以分册原生值为准（手机整屏邀请函本就允许 9:19.5）。

## 3. 字体栈（≤3 款）

- 中文全部宋体衬线：**Noto Serif SC VF**（500/700/800），禁黑体。
- 西文 caps：**EB Garamond Regular**（YEAR-END GALA / TIME / ADD / PINYIN 行），letter-spacing 0.12–0.33em。
- INVITATION 巨字：**Bodoni Moda VF**（`fonts/english-bodoni-moda/BodoniModa-VF.ttf`，OFL 可商用；wght 400–900 / opsz 6–96）——【2026-09-24 v2】用户否决 EB Garamond 替代方案后入库的真轻 Didone；用 `font-variation-settings:'opsz' 96,'wght' 400` 出发丝级高反差。Rozha One 过重已否决；EB Garamond 降级为兜底。
- 数字：**Times New Roman**（2025/12/26/19:00 lining；EB Garamond oldstyle 不可用，见 §10）。
- 挂载路径（相对 HTML 所在的两级深目录，如 `trials/ivory-gold/`、`tests/realorder-01-invitation/`）：`../../fonts/source-han-serif/NotoSerifSC-VF.ttf`、`../../fonts/english-eb-garamond/EBGaramond-Regular.ttf`、`../../fonts/english-bodoni-moda/BodoniModa-VF.ttf`。
- ⚠️ **引擎 @font-face 端点 bug（2026-09-24 实测）**：导出引擎对 `font-weight:` 区间描述符的**端点值匹配失败**（请求端点字重→整只掉进系统回退字体，横向 advances 膨胀 ~19–62%）。规避：描述符写 `300 800`（EB）/`200 900`（Noto），**任何 CSS 请求的字重都不许落在区间端点上**（EB 请求 400 ✓、Noto 邀请函用 800 不用 900）。VF 轴显式声明（`'wght' 400`）可额外稳住 Bodoni 实例。
- ⚠️ **B 变体全 sans-serif（2026-10-12 像素复测确认）**：B 从 VN caps 到 BRANDED/LIVING/SUMMIT/时间日期/footer **全部无衬线**（几何感 grotesque，非 A 的衬线世界）。现行栈 **Roboto Flex VF**（`fonts/english-roboto-flex/RobotoFlex-VF.ttf`，OFL 可商用）——Vietnamese 变音符全覆盖，已逐字目检通过。衬线禁令（§8.2）对 B 不适用；B 与 A 共用色板但字体世界独立。

## 6. 布局原型

- **原型 A · 居中请柬塔（本案例）**：logo 锁 → 两行引言小字 → 西文巨字 → 中文巨字（拼音横穿）→ 花括号副题 → 落款两行 → 胶囊 → 竖线 → 时间地点 → 全宽插画收底。层级 3 层：巨字塔 / 信息层 / 插画层。所有文字元素**单轴居中**，轴上密度节奏「紧—松—紧」。
- **原型 B · 左字右扇峰会**：左列字阶（logo → caps 引言 → 两行巨字其一实心其一双线夹字 → 时间日期），右下**金缎带漩涡**承担「金立体」分量，footer 沉底。文字区与扇面区以 y≈1000 分界互不侵犯。
- **原型 C · 3:4 邀请卡压缩**：A 的塔保字号比（INVITATION : 邀请函 ink ≈ 119:158），插画区砍半，信息层只留胶囊+时间。

## 7. 组件语言（配方）

- **拼音横穿巨字（A 签名）**：红拼音行 absolute 居中，置于邀请函 z 之下；行 y 对准巨字 ink 竖直中点（±5px）。两侧超出巨字簇的红行完整显形，字隙处红行透出——「经纬织字」效果。生产时拼音由用户文案自动生成（全大写、去声调、空格分词）。
- **高瘦巨字**：邀请函用 900 重 + `transform:scaleX(0.6)` 压缩成原案例高瘦比例（原案例字体为天然 condense 宋，Noto Serif 需变形模拟）；INVITATION 维持 EB Garamond 自然比例。
- **胶囊细框**：2px 描边全圆角，无底色无边框投影，文字铜棕——「印章式」克制。
- **竖发丝线**：信息塔的节拍器，只一条，1px 实色。
- **引言斜杠行**：`与/您/共/赴` 用半角斜杠做非连读节奏（对照 B 的 VN caps 两行纯空格分词）。
- **badge 圆盘**：实心铜棕圆 + 白字，与 YOUR LOGO 组成锁形 logo——生产换用户徽标。
- **金沙插画融合层（A 底部）**：【硬·2026-09-24 v3/v4/v5/v6 改版】插画位必须是**真实素材的去底马匹**（PNG/WebP alpha），居中浮于金沙渐变上，**禁任何投影**（v5 批注「投影去掉」：软椭圆地影 + img drop-shadow 全部移除，马以剪影体量直接融进金沙渐变，无投影更显轻、更「浮立」）；**题材不锁死「白马摄影」**——v3/v4/v6 用户供图鎏金马雕塑、水墨骏马、水墨奔马相继过审，命名级特征是「金沙渐变上的去底礼遇意象」（写实摄影、雕塑、水墨质感等同合格）；**体量要大气且基本占满（v4「太小气」→v5「基本占满」→v6 横构图近满幅）**：img 高 ≈**800px**（占画布高 ~34%），低于 700px 判「小气」不合格；v6 奔马为横构图（631×473，aspect≈1.33），left 6 → 宽≈1067 近全幅横贯（x6–1073）；**禁 SVG 手绘马/沙丘**（紧急降级须声明）；素材四周永无边框。（v1「整幅照片铺底 + mask 渐隐」、v2「白马摄影唯一定死」、v3/v4「软投影融景」方案均已被用户批注替换；`white-horse-front.png`（鎏金马雕塑）、`golden-horse-ink.png`（鎏金水墨骏马 v4/v5 现行）、`white-horse-cutout.png`（Unsplash 白马抠图）、`white-horse-gold-field.jpg` 留作备选库存。）
- **金扇缎带漩涡（B，2026-10-12 终版配方 v18）**：纯 SVG 几何，**结构 = 扭转缎带的漩涡收敛**（非折扇、非刃片）。每条缎带 = 中心线二次贝塞尔（尖 T → 控制点 C → 终点 E）+ 沿法线半宽 w(t) 线性渐宽生成的**填充多边形**（尖端窄 8–22px、根宽 66–114px，端头平切呈刀尖）；三层叠涂：①带身填充 = 沿轴渐变（象牙 → 淡金 → 琥珀 → 深金）；②金面 = 中心线→右缘的半带多边形，透明度沿轴 0→0.85–1（模拟「扭转」：上部亮面朝光、下部转出金面）；③左缘高光 ridge `#fffef8` 2.2px op.85（缎间亮缝）。**三个编组**（画布 1080×2160 实测锚点）：**中带 6 条**——右组 4 条底端收拢成金浪（c3 尖(790,1010)w50→E(790,2210)w110 弓左 C(690,1640)；c4 (915,1040)w65→(852,2210)w114；c5 (1040,1095)w30→(960,2210)w108；c6 (1072,1100)w20→(1075,2210)w102），金面渐变 `.5 #df9f2e .85→.72 #cf8e22 1→1 #b87214`；左组 2 条金面中段峰值后向左下**淡出**（c1 (620,1120)w15→(640,2170)w66；c2 (640,1002)w22→(700,2210)w102；金面 `.48 #cf8e22 1→.88 op.15→1 op0`，带身回浅 `#e8cd92`）——底部金浪因此只从 x≈740 起（实测 y2100 排布 740–845/847–917/922–1020/1025–1080）。**左臂 5 条**（先画、被中带压住折点）：a1 (590,1210)w50→刀尖(100,1500)w56；a2 (630,1310)→(122,1582)；a3 (670,1405)→(192,1628)；a4 (710,1495)→(285,1675)；a5 尾卷 (760,1660)w30→(335,2000)w14；臂亮面更白（`#fffef8→#eed9a8`），金面弱（峰 op.3–.5），臂下模糊影 stroke `rgba(140,100,40,.13)` w+16 `feGaussianBlur 7`。**幽灵折面 2 条**（最底层）：h1 (680,1120)w55→(345,1730)w72、h2 (730,1300)w50→(400,1900)w66，淡金 `#f7ebc9` 级——填臂与中带间的空档（案例该处是几乎融入 bg 的宽亮面）。**收尾**：径向深金浪 `cx(780,2000) r700`（`#7e4a0c` op.55 → 0）+ 眼部 `cx(620,1960) r320` op.3 两层 rect 罩面；中带尖下加短模糊影（w0+10, 前 8 个采样点）。**判合格**：尖部落 y1000–1120 错落带、左臂刀尖阶梯贴 (109,1455)–(285,1675)、底部金浪左界 x≈740、亮/金面交替的缎带质感、footer 文字区零侵犯。**模拟上限声明**：案例为照片级 3D 渲染（面内有环境反射与微纹理），代码复刻达「结构+色域+氛围乱真」，微纹理不强求。四轮迭代教训：圆头 stroke 长条=药丸感（×）、稀疏曲线 bar+hub=断线感（×）、实心梯形墙=死板（×）、**折扇放射直板**（v11–v14）渲染呈药丸指（×，2026-10-12 side-by-side 推翻）——**must be 渐变填充扭转多边形+刀尖+编组叠序**。

## 8. 禁则

1. 【硬】A 全图彩色 ≤1 处（陶土红拼音行）；金沙暖调只许出现在插画融合层。
2. 【硬】中文禁黑体、西文 caps 禁无衬线——全版衬线是本族底线（**A 变体**；B 变体全 sans-serif 反向禁衬线，见 §3，两变体字体世界互斥）。
3. 【硬】插画位必须真实素材的去底马匹（PNG/WebP alpha）居中，**禁任何投影**（v5 批注：地影/drop-shadow 全撤）；题材不锁白马摄影（v3/v4：鎏金雕塑、水墨马均合格）；体量 ≥700px 高、基本占满底部区域（v5：800px ≈34% 画布高过审，<700px 判「小气」）；禁 SVG 手绘白马/沙丘作主视觉。
4. 【硬】拼音行必须横穿巨字 ink 中点且 z 序在下；不许挪到巨字上方独立成行。
5. 【硬】absolute 组容器必须显式宽高（防零宽塌陷，同 newchinese §8.9）。
6. 【默认】A 全部内容单轴居中（x=540）；B 左轴 x=75。
7. 【默认】胶囊/竖线/发丝分隔件全图各 ≤1 处。
8. 【默认】微字地板 21px（画布），低于则删。
9. 【默认】bg 暖白禁加纹理噪点；「纸感」来自暖白+铜棕对比。

## 10. 技术注记

- 数字一律 Times New Roman（EB Garamond oldstyle 缺陷，organic-sweep/zen-collage 同款结论）。
- **去底白马管线（v2）**：Unsplash `photo-1553284965-83fd3e82fa5a`（Unsplash License 可商用；白马侧身奔跑向右、金尾）w=2000 取图 → cv2 `grabCut`（亮度三段种子：L>135 确 FG / >92 疑 FG / <70 疑 BG，10 轮）→ 形态学开闭 + 连通域保大去渣 → 3px erode + 高斯羽化 → 轻暖调（R×1.03 B×0.93）→ `assets/white-horse-cutout.png`（1149×797）。cv2 经 `pip3 install opencv-python-headless -i https://mirrors.aliyun.com/pypi/simple/` 入环境（numpy 随装）。**v3 起降为备选库存**，管线本身保留（同族照片抠图复用）。
- **现行素材（v6）**：`trials/ivory-gold/assets/golden-horse-gallop.png`——用户提供（原文件 `huaban-7031607399.png`，花瓣网下载），鎏金水墨**奔马**（扬鬃腾跃横构图），658×658 RGBA 真透明底（透明占比 75.8%），alpha 阈值 32 裁净 → **631×473**（横构图 aspect≈1.33，v6 以 left 6 / 高 800 近全幅横贯）。前版 `golden-horse-ink.png`（鎏金水墨骏马 400×474，v4/v5 现行）降为备选库存，`white-horse-front.png`（鎏金马雕塑 369×536）再前一批。✅ 2026-10-13 用户整体确权「素材目前没什么问题，可以商用」——鎏金马系列（gallop/ink/front 三件）均可商用（花瓣网采集，原始出处未追溯，清单见 ASSETS.md）。
