# viz-studio 通用设计护栏（所有格式与风格叠加遵守的硬规则）

> 这里是底线，不是风格。格式分册（formats/*）写平台硬规格，风格分册（styles/*）写审美差异，
> 两者都必须叠加遵守本文件。规则标注：**【硬】违反即错；【默认】强默认，破例需理由。**
> 来源：改写自 artboard（GreenChennai）guardrails / typography-rules；PPT 纪律吸收归藏 guizang-ppt-skill。

---

## 1. 画布纪律（违反 = 导出必翻车）

- 【硬】`body { margin: 0 }`；唯一顶层容器 `.poster` 用**固定像素尺寸**（按 SKILL.md 路由表），`overflow: hidden`。
- 【硬】禁止依赖滚动：单幅物料没有「往下看」，首屏即全部（数据长图除外——它逐屏各有重点）。
- 【硬】禁止 `position: fixed` / `100vh` / `100vw`——导出语境下语义错误，用画布尺寸代替。
- 【默认】内容安全边距：画布四周 ≥6% 宽度（被平台圆角裁切的场景 ≥8%，印刷另看出血）。
- 【硬】装饰可贴边出血，**文字和 logo 永远在安全边距内**。

## 2. 编辑纪律 + CRAP 四原则

- 【默认】密度目标 4/10：每个元素都要挣得位置；最高质量的动作通常是删减。
- 【硬】强调色只给最先该看的 1–2 个元素；到处强调 = 没有强调。
- 【硬】一图一个视觉焦点；层级最多 3 层（主标 / 辅文 / 标签）。
- 【硬】文案逐字来自用户或经确认，**不编造数据、不虚构促销条款**。
- 【硬】CRAP 自检口诀「靠不齐、不重复、差不多」——出现任何一个画面就废：
  - **C 对比**：不一样就要明显不一样（主标 ≥ 正文 1.5–2 倍），「差一点点」比「没差别」更糟；
  - **R 重复**：同一字体组合、色板、圆角、图标风格贯穿全图；
  - **A 对齐**：没有元素可以随便放；单版面只用一种主对齐；
  - **P 亲密**：相关的靠在一起，组内间距 < 组间距（板块间距 = 组内 2–4 倍）。

## 3. 排版规则

- 字号阶**用比例生成，不要随手敲**：r=1.25（通用）或 r=1.414（海报展示型）。
  基准 16px：16→20→25→31→39→49。画布 1080 宽海报换算：主标 88–160，副标 40–56，正文 26–32，标签 20–24。
- 【默认】行高：标题 1.1–1.3；正文 1.6–1.8（中文黄金组合：16px + 1.75 + 每行 30–35 字）。全图行距一致。
- 【默认】中文字距：大标题 0.02–0.06em；**正文禁止负字距**。每行正文 ≤22 字（海报短栏）；段落宽 ≤ 画布宽 70%。
- 【硬】字体配额 ≤3 款（标题/正文/数字各司其职）；数字放大后比周围汉字加一档字重。
- 【硬】粗体与斜体不同时用；中文标题用粗体不用斜体；标题禁下划线。

### 3.1 中文排版三条底线（clreq）

1. 【硬】行首行尾禁则：句读点（。，、；：？！）与收尾引号/括号不得出现在行首；开始引号/括号不得在行尾。
2. 【硬】中西文混排之间加 1/4 空格（`共计 24 帧`）。
3. 【硬】中文三不：不拉长压扁汉字、不用假粗体/假斜体（用真字重）、长文不排斜体。

### 3.2 标题语义断行

- 【硬】展示文字（标题/大字卡，≤20 字）禁止依赖自动换行——断点手动给，写两个 `<span style="display:block">`，断在语法边界（主谓/动宾之间），**不许劈开词**。
- 【硬】孤字不成行：段落末行 ≥2 个汉字（1 字 + 标点 = 违规）；多行标题末行 ≥3 字。宁可改写文案。
- 【默认】两行标题行长比约 1 : 0.6–1；换色边界 = 断行边界（关键词行用强调色）。
- 【硬】`word-break: keep-all` 只用于标题/短句，正文段落禁用；`text-wrap: balance` 只许在语义断点就位后做匀称。

## 4. 色彩规则

- 【硬】全部颜色走 `:root` tokens（`--c-ink/--c-bg/--c-primary/--c-accent/--c-muted`），禁止散落裸 hex。
- 【默认】主色 60 / 辅助 30 / 强调 10；Itten 面积比：亮色小面积、暗色大面积（黄:紫 = 1:3，橙:蓝 = 1:2）。
- 【默认】高级感公式：低饱和底 + 一点高饱和；文字禁纯黑（从 `#111` 起步），底色慎用纯白。
- 【硬】正文对比度 ≥4.5:1（大字 ≥3:1）；照片压字必须先压暗再验对比度。
- 【硬】禁「蓝紫渐变 + 发光」组合（最大众脸的 AI 味）；风格分册禁则另行叠加。

## 5. 反 AI 味自检 12 条（交付前逐条过）

最高优先级审美约束：**这张图截到社交平台，会不会被说「一眼 AI」？**

1. 没有「紫→蓝」渐变。
2. 没有 AI 高发字体当主标（Inter/Roboto/思源默认字重直出）——主标用「性格款」。
3. 没有渐变文字滥用（烫金/铬金类 fx 除外，一图 ≤1 处）。
4. 没有等权重标题阵列——层级拉开 ≥1.5 倍字号差。
5. 没有嵌套卡片（卡片里套卡片）。
6. 没有默认居中构图当唯一构图——居中要有理由（仪式感/对称主体）。
7. 强调色 ≤2 处，且给了最先该看的东西。
8. 没有装饰性英文小字堆砌（无意义的 "DESIGN / ART / 2026" 眉题）。
9. 正文行宽 ≤22 个汉字，行高 1.6–1.8。
10. 没有均质圆角卡片铺满画面（卡片阵列墙）。
11. 留白 ≥25%，且位置有意图（呼吸位在焦点旁，不是四边均匀镶边）。
12. 删掉任何一个元素会更差吗？删掉没影响的，删。

## 6. 素材纪律

- 【默认】用户图片用 `object-fit: cover`；多图色调不统一时加统一滤镜（duotone/低饱和）。
- 【硬】真实素材优先：用户供图 > 已授权图库 > 生成图（兜底，必须声明）。图库素材保留署名与版权标记。
- 【硬】依赖真实拍摄的品类（菜品/环境/人物探店）开工前就声明「需要你供图」，不许拿图库糊弄。
- 【硬】图标用内联 SVG（如 Tabler/Lucide），**禁 emoji 当图标**。
- 【硬】图表必须有真实数据来源；数据长图的数字逐个核对。

## 7. 分媒介附加纪律

### 7.1 屏幕/社交（小红书、公众号、朋友圈、长图）

- 【硬】公众号封面关键信息居中在中央 383×383 安全区（转发只露这里）。
- 【默认】小红书封面标题关键词前置，3 秒可读；全套同比例。
- 【默认】数据长图逐屏一重点；每屏仍有完整构图（用户会截单屏转发）。

### 7.2 印刷（名片、海报、三折页、易拉宝、道旗）

- 【硬】出血 3mm；重要文字距成品边 ≥3mm（名片）。
- 【硬】易拉宝上下 25/30cm 盲区不放关键信息；正文 ≥90px（150dpi）。
- 【硬】道旗上下 10–15cm 套杆/扣眼区不放关键信息；关键内容居中央 94% 宽（防摆动遮挡）。
- 【硬】最小字号：名片 7pt；A4 海报正文 ≥9pt。印刷文字一律 ≥12pt 起评，特殊小字按物料表。
- 【默认】三折页内板收窄 1–2mm；跨折线不放文字与面孔。
- 【默认】道旗信息 ≤3 组（主标＋时间地点＋logo）；主标字高 ≥200mm（5m 旗基准），按「视距 m×5≈字高 mm」校核；双面输出同版或水平镜像，不另设计第二版。

### 7.3 PPT/演示（叠加 guizang checklist）

- 【硬】1920×1080 下标题 ≥36px、正文 ≥24px；投屏 deck 卡片描述 ≥16px、meta ≥14px——放不下先删文案或拆页，不许缩字号。
- 【硬】一页一论点；底部预留分页组件安全区（内容不过 93vh）。
- 【默认】明暗节奏：连续 3 页同底色 = 视觉疲劳；每 3–4 页插一个 hero/幕封页。
- 【默认】动效克制：每页一个语义化动效即可；禁所有页统一 fade-up。
- 【硬】大字号双约束限高 `font-size: min(Xvw, Yvh)`，只用 vw 在 16:9 会溢出。

## 8. 文字溢出修复优先级（按序执行，不许跳步）

先分清：**出卡片框**（文字画出背景/边框）走 0→5；**出画布**（被裁掉）走 1→5。

0. 结构修复（首选）：`height` → `min-height`；去掉 top+bottom 双锁；长文案加 `line-clamp`。禁止用 `overflow:hidden` 兜住文字（裁半截比出框更难看）。
1. 减小正文字号（下限：知识卡 16px / 海报正文 26px，不许再低）；
2. 减小行高（下限 1.4）；
3. 减小卡片内边距；
4. 换更紧凑布局（双栏替单栏）；
5. 精简文案——**必须先征得用户同意**。

> 预防优先：先估后写，同组卡片统一 `min-height` 到最大估高。出框后再缩字号是下策。

## 9. 出图前自检清单（每轮必过）

1. 主标 3 米外可读？信息层级清晰（≤3 层）？
2. 文字无溢出、无截断、无换行孤字？标题断行过禁则、语义完整？
3. 字体确实加载（不是系统回退）？——@font-face 路径相对 **HTML 自身位置**逐级核对；Chrome 对失效字体路径**静默回退不报错**（quote-pop 事故 2026-10-10：少写一级 `../`，定稿图整块引言用了回退衬线），导出后必须抽验文字块字形；数字用对字体与字重？数字列 tabular-nums 对齐、千分位？
4. 对比度达标？强调色 ≤2 处？
5. 装饰是否抢了主体？删掉一个元素画面会更好吗？
6. 画布尺寸/倍率正确？印刷物料出血/盲区/最小字号合规？
7. 反 AI 味 12 条逐条过（§5）？
8. PPT：逐页过 guizang P0 清单 + 本文件 §7.3？
9. 反参照（用户「不要什么」）逐条核对？

## 10. 规则优先级（冲突时从上往下）

1. 用户反参照与明确要求
2. 平台/印刷硬规格（formats/* 与路由表）
3. 风格分册禁则（styles/*）
4. 本护栏【硬】条款
5. 本护栏【默认】条款
